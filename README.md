# Threadline — интернет-магазин одежды

Лабораторная работа №1 Вариант 5.

## Что реализовано
- 4 страницы: главная, каталог, регистрация, вход
- Адаптивная вёрстка (desktop/mobile)
- 6 товаров в каталоге
- Поиск и фильтрация по категориям (JS)
- Клиентская валидация формы регистрации (JS)
- Показ/скрытие пароля

## Запуск
Открыть `index.html` в браузере или запустить через Live Server.

## Технологии
HTML5, CSS3 (Flexbox/Grid), Vanilla JavaScript, Git.
